# <kbd>module</kbd> `adabmDCA.steering`
Steered sampling: hard alphabet and Hamming constraints, linear distance biases and weighted callbacks.

`adabmDCA.steering.sampling` holds `SteeringConfig` and the MCMC and PTT samplers, `adabmDCA.steering.support` the constraints and the exact constrained profile, and `adabmDCA.steering.kernels` the constrained Gibbs updates. The anchor restricted to Hamming windows is `adabmDCA.anchor.window.WindowedAnchor`.
