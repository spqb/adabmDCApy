    function select_inactive_elements

    select_inactive_elements(
    Dkl: Tensor,
    mask: Tensor,
    fraction: float
) → Tuple[Tensor, int, int]

    Activates the inactive off-diagonal coupling entries with the largest Dkl.

    Entries are counted once per symmetric pair (i < j). Only inactive entries are eligible: active ones are already refitted at every gradient update. At least one entry is activated while inactive entries remain, and never more than remain.

    Args:

    • Dkl (torch.Tensor): Element-wise Kullback-Leibler divergence matrix.
    • mask (torch.Tensor): Symmetric boolean mask of the active couplings.
    • fraction (float): Fraction of the inactive unique entries to activate.

    Returns:

    • Tuple[torch.Tensor, int, int]: Updated symmetric mask, number of entries requested (int(fraction * inactive)) and number actually activated.
